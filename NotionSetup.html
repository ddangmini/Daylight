노션의 할 일을 바탕화면으로

표 형태의 데이터베이스에 있는 할 일을 가져옵니다. 위젯에서 완료를 체크하거나 해제하면 노션 표의 완료 속성도 변경됩니다. 일반 페이지의 체크리스트는 이 버전의 연결 대상이 아닙니다.

1. 노션 내부 연결 만들기

  1. 노션 연결 관리에서 본인 워크스페이스의 내부 연결을 만들고 이름을 Daylight로 정합니다. 노션 화면에 따라 ‘통합 / Integration’으로 표시될 수 있습니다.
  2. 콘텐츠 읽기와 업데이트 권한을 켭니다. 새 항목 추가 권한은 이 버전에 필요하지 않습니다.
  3. 내부 연결 토큰을 복사합니다. 이 토큰은 채팅에 보내지 않고 위젯의 연결 설정에만 입력하세요.
  4. 노션에서 할 일 데이터베이스를 열고 … → 연결 / Connections → 연결 추가로 Daylight를 연결합니다.
  5. 데이터베이스 자체의 링크를 복사합니다. 다른 페이지에 놓인 연결된 보기를 쓰면 원본 데이터베이스를 열어 링크를 복사하세요.

2. 위젯의 ‘연결 설정’ 입력하기

  • 토큰: 복사한 내부 연결 토큰
  • 데이터베이스 링크: 할 일 표의 링크
  • 완료 속성 이름: 표의 상태 열 이름. 예: 상태 / Status / 진행 상태
  • 완료 상태 이름: 완료를 체크했을 때의 옵션. 예: 완료 / Done
  • 체크 해제 시 상태: 다시 미완료로 바꿀 때의 옵션. 예: 할 일 / 시작 전 / Not started
예시: 표의 ‘상태’ 열에 ‘할 일 · 진행 중 · 완료’가 있으면, 속성 이름은 상태, 완료 상태는 완료, 체크 해제 시 상태는 할 일로 입력합니다. 진행 중도 미완료 항목으로 표시되며 체크하면 완료로 바뀝니다. 체크를 해제하면 설정한 ‘할 일’로 돌아갑니다.

체크박스로 완료를 관리하는 표도 지원합니다. 완료 속성에 체크박스 열의 이름을 입력하세요. 이때 상태 옵션 이름은 사용하지 않습니다. 데이터베이스에 표(데이터 소스)가 여러 개면 노션의 데이터 소스 ID도 입력해야 합니다. 노션에서 해당 데이터 소스의 ‘데이터 소스 ID 복사’ 메뉴로 복사할 수 있습니다.

사용 방법

저장하고 연결하면 목록이 표시됩니다. 실행 중 5분마다 노션 변경사항을 가져오며 새로고침도 가능합니다. 완료 표시를 바꾸면 노션에 바로 반영합니다. 수정이 확인될 때까지 기존 체크 상태를 유지하며, 오류가 나면 안내를 표시합니다. 체크 요청이 실패하면 실제로 반영되었을 가능성도 있으므로 새로고침해 확인하세요.

최근 변경된 항목부터 최대 200개를 가져오고 그 안에서 미완료 항목을 먼저 표시합니다. 제목과 완료 여부, 첫 번째 날짜 속성의 기한을 표시합니다. 할 일 추가·이름 변경·삭제는 노션에서 진행하세요. 위젯의 ‘이 기기의 할 일’은 별도로 저장됩니다.

업데이트해도 다시 연결할 필요가 없습니다

같은 PC와 윈도우 계정에서 패치를 적용하면 연결 정보가 보존됩니다. ‘연결 해제’는 이 기기의 저장된 토큰을 지우며, 노션의 내부 연결 자체를 삭제하지는 않습니다. 토큰을 폐기하려면 노션 연결 관리에서 처리하세요.
